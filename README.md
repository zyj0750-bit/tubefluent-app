# tubefluent-app
TubeFluent — AI-powered English learning platform-improve your English through real content, with AI feedback.
 **Live:** [https://tubefluent.com](https://tubefluent.com)                                                                                                                                                                      TubeFluent helps learners improve English by learning from content they actually enjoy —YouTube videos, podcasts, and  books —with AI-powered feedback on writing, speaking, and pronunciation.                                 ## Features                                                                                                                                                                                                                     - 🎬 **Video learning** —YouTube videos with dual subtitles and tap-to-look-up                                         
 - 🎧 **Podcasts** —curated podcast library with transcripts
 - 📚 **Reading** —CEFR-graded books and uploaded PDFs
 - ✍️**AI writing feedback** —grammar, vocabulary, and structure
 - 🗣️**AI speaking practice** —real-time conversation with pronunciation scoring
 - 🧠 **Adaptive learning** —CEFR placement test, growth engine, spaced repetition
